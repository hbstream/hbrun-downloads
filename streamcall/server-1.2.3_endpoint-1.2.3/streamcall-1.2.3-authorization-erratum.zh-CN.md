# StreamCall 1.2.3 授权说明更正

适用于 `StreamCall-Server-1.2.3-Linux-x86_64.tar.gz` 随包操作手册第 6 节。该节将“业务集成授权”描述为同时包含 Endpoint SDK 集成权益，此处表述有误。交付与签发以以下说明为准：

| 授权范围 | 实际权益 |
| --- | --- |
| 生产部署授权 | 官方 Server、调度中心和官方终端的私有部署 |
| 业务集成授权 | 生产部署能力与业务数据 API |
| 调度集成授权 | 业务集成能力与完整调度 API |
| Endpoint SDK 集成 | 需另行约定并在授权文件中明确启用，可与上述范围组合 |

客户将 Endpoint SDK 集成到自有 Windows、Linux、Android 或 Web 应用时，还须登记客户应用及终端安装身份。仅下载 SDK 包、取得业务 API 或完整调度 API 权益，均不自动授予 Endpoint SDK 集成权益。

本更正不改变 1.2.3 发行包、授权校验行为或既有交付包文件的 SHA-256。交付人员应将本说明与 1.2.3 Server 包同时提供，并在授权申请时核对实际签发的权益。
